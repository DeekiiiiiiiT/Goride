A package is one garage visit. It lists parts; each part keeps its own schedule. Decoupled Architecture

A service package never overrides or resets a part's lifecycle counter. Brake fluid listed inside Basic Service is evaluated as an inspection point or deferred until its dedicated 40,000 km trigger matures.
