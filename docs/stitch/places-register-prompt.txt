ROAM DOMINION — PLACES REGISTER FULL DESIGN PROMPT (GOOGLE STITCH)




Roam Dominion - Places Register (Desktop Admin, for the owner):

Design high-fidelity desktop admin screens

BRAND IDENTITY:
- Match the existing Roam Dominion admin style:
  - dark navy left sidebar
  - white top bar with a search field and the owner avatar
  - white cards and compact data tables
- LIGHT MODE (default):
  - Primary: Dominion Blue (#0153dc) — primary buttons, links, selected rows, active filters
  - Primary container: Pale Blue (#dbe1ff) — selected chips, row selection tint
  - Success / verified / on Plug: Green (#006e31)
  - Warning / pending / issues: Amber (#d97706)
  - Error / destructive: Muted Red (#a83836)
  - Neutral: Slate (#797a84) — borders, muted text, icons
  - Background: Cool off-white (#faf8fe)
  - Surface cards: Pure white (#FFFFFF)
  - Text primary: Charcoal (#30323b)
  - Sidebar: Dark navy (#0f172a) with white text; the active item is a solid Dominion Blue pill
- DARK MODE:
  - Primary: #5b8def
  - Primary container: #1e3a5f
  - Success: #4ade80
  - Warning: #f59e0b
  - Error: #f87171
  - Neutral: #94a3b8
  - Background: Deep navy (#0b1220)
  - Surface: #111a2e
  - Text primary: #e2e8f0
- Place type chips are neutral (white or grey with a small icon), never coloured by group
- Status chips:
  - Verified: green dot
  - Pending: amber dot
  - Learnt: blue dot
  - Rejected: red dot
  - Duplicate: slate dot
  - Closed: slate outline
  - Anomaly: amber outline
- Issue chips: small amber outline pills ("Pin not checked", "No brand", "Parish text differs", "Outside Jamaica")
- No gradients, glassmorphism or 3D. No AI badges, "REGION" badges or "LOC:" footers.
- Typography: Inter. Codes, counts, coordinates and dates use the mono font with tabular numerals.
- Brand name in the sidebar: "Dominion — Roam Admin Console"
- Jamaica context everywhere:
  - the 14 parishes, plus towns
  - Plus Codes (e.g. "7795X2GP+6C9")
  - +1 876 phone numbers
  - local fuel brands (TotalEnergies, Rubis, Texaco, FESCO, Cool Oasis, Petcom, Unipet, Gulfstream)

DESIGN PRINCIPLES:
- Desktop-first (1440px wide), keyboard friendly; a phone version for the list and the drawer
- The list never disappears: records open in a right-side drawer over the list, and closing it returns to the same scroll position
- Every row shows what is missing (issue chips) so staff know what to fix
- Every change shows a preview first and asks for a short reason, and every change is kept in History
- Parish is never typed: it is worked out from where the pin sits on the map
- A new place starts with NO pin; nothing can be saved until a pin is dropped
- Gas stations open the existing Station drawer; this section's drawer is for every other place type
- Light theme default, dark mode variant
- Strict 8px spacing grid, 12–16px card corners, hairline borders, very soft shadows, skeleton loading

- Side-by-side merge cards with "Keep this one" radio
- Toasts: "Saved — kept in History", "3 places updated", "Merged"
- Skeleton loaders, error card, empty state

INTERACTIONS:
- Clicking a row opens the drawer; Esc closes it and returns to the same scroll position
- The URL keeps every filter and the open place (&place=<id>), so a view can be shared
- Search waits until typing pauses
- Ticking rows slides up the bulk bar; every bulk action opens its confirm dialog first
- Dragging the pin updates the parish line and the duplicate check live
- "Verify" stays disabled until every checklist step is ✓, and the tooltip lists what is missing
- Import "Save" unlocks only after a check with zero errors
- After save, a toast appears and the row updates in place without reloading the list
- A gas station row opens the existing Station drawer instead of this drawer
