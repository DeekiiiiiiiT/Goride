## Brand & Style

The design system establishes a high-density, tranquil, and systematic workspace engineered for enterprise fleet administrators and vehicle maintenance engineers. Master data reference workflows demand uncompromised clarity, spatial predictability, and ergonomic comfort over long hours of template editing, telemetry monitoring, and specification drafting.

The design philosophy combines **Modern Functional Corporate** with **Micro-Architectural Precision**. Visual noise is eliminated to honor data density:
- **Atmosphere:** Cool-toned, airy, and clinical without feeling sterile. The pairing of light, tinted background planes with a high-contrast deep navy structural sidebar grounds the administrative scope.
- **Visual Cadence:** Crisp 1px hairlines frame information hierarchies, backed by featherweight blue-tinted elevation shadows that subtly float interactive modules without muddying visual pathways.
- **Tone:** Authoritative, methodical, and calm. The UI avoids dramatic ornamentation; every color accent serves an operational or taxonomy state (such as distinguishing OEM car maker specifications from aftermarket component metrics).

## Colors

The palette balances deep nautical enterprise anchors with soft porcelain canvases and hyper-focused functional indicators:

### Core Hierarchy & Foundations
- **Primary (`#0153dc`):** Anchor cobalt blue for active navigation anchors, primary system triggers, focused outlines, and Part Maker entities.
- **Primary Container (`#dbe1ff`):** Soft periwinkle wash used behind active primary selections, row highlights, and part-level badges.
- **Surface Canvas (`#faf8fe`):** A barely perceptible cool-lavender off-white canvas that softens screen glare.
- **Surface Card (`#ffffff`):** Pure white container surfaces providing crisp separation over the tinted canvas.
- **Tint Panel (`#f3f4fb`):** Inset secondary workspace surface applied to parameter groupings, batch config bays, and filter strips.
- **Border / Hairlines (`#e6e7ee`):** Subtle structure borders that divide cells, table heads, and card segments without visual friction.
- **Input Border (`#c5c6d0`):** Balanced boundary outline ensuring accessibility across text inputs, select dropdowns, and data steppers.
- **Sidebar Canvas (`#0b1220` to `#0f172a`):** Deep oceanic navy shell establishing high-contrast structural framing for primary product navigation.

### Text & Semantics
- **Text Main (`#30323b`):** High-legibility carbon ink for labels, header lines, and core data readouts.
- **Text Muted (`#5d5f68`):** Mid-tone graphite for table captions, secondary metadata, unit dimensions, and disabled hints.
- **Semantic Badging & Taxonomy:**
  - *Car Maker (OEM):* Green text `#006e31` over pill background `#e6f4ea`.
  - *Part Maker (Aftermarket/Component):* Blue text `#0153dc` over pill background `#dbe1ff`.
  - *Roam Policy (Governance Rule):* Slate text `#475569` over pill background `#f1f5f9`.

## Typography

Typography bridges rapid scanning and technical rigor.
- **Inter** provides high legibility for conversational text, modal dialogues, headings, and standard administrative control labels.
- **JetBrains Mono** governs all numerical values, chassis VIN references, part catalog serial codes, template IDs, intervals, and fleet operational metrics. Its monospaced baseline guarantees vertical scanning alignment across dense multi-column tabular data grids.
- Font sizes favor ergonomic desktop densities with `13px` serving as the workhorse body and data-label size, preventing excessive scrolling during deep template authoring.

## Layout & Spacing

The layout model implements a fluid split-view shell calibrated for high-resolution widescreen monitors (1440px+) while retaining resilient stacking for responsive maintenance field tablets (768px - 1024px):

- **Structural Grid Architecture:**
  - Fixed-width collapsible primary sidebar (`260px` default, `72px` compact icon-only).
  - Main template canvas dynamically fills remaining viewport width with maximum horizontal stretch for data grids.
  - Secondary drawer/inspector panel occupies a fixed `380px` slide-out on the right when deep-editing maintenance rule expressions.
- **Vertical Spacing Rhythm:**
  - Base structural increment is 4px.
  - Form field stacks and parameter key-value groups use `0.75rem` (`space-md`) spacing.
  - Card interiors leverage `1.5rem` (`space-lg`) internal padding, tightening down to `1rem` on tablet screens.
  - Tabular rows use compact vertical cell padding (`8px` top/bottom) with generous horizontal padding (`16px`) for ease of horizontal scanning.

## Elevation & Depth

Visual hierarchy operates through disciplined surface tonal layering paired with faint ambient diffusion, explicitly eschewing muddy dropshadows:

1. **Layer 0 (Canvas Base):** Background surface `#faf8fe`, completely flat.
2. **Layer 1 (Recessed/Tooling Bays):** Tint panels (`#f3f4fb`) inset with 1px border `#e6e7ee`, creating sub-sections inside large white workspaces.
3. **Layer 2 (Primary Floating Work Surfaces):** Card containers (`#ffffff`) bounded by a 1px hairline border (`#e6e7ee`) and supported by a hyper-diffused ambient shadow:
   `box-shadow: 0 4px 16px 0 rgba(1, 83, 220, 0.04);`
   The blue tint inside the shadow anchors the surface harmoniously to the primary canvas instead of casting dirty gray tones.
4. **Layer 3 (Modals, Overlays & Flyout Menus):** Pure white `#ffffff` elevated with structural hairline outline `#c5c6d0` and dual-tier elevation:
   `box-shadow: 0 4px 12px 0 rgba(11, 18, 32, 0.06), 0 12px 32px 0 rgba(1, 83, 220, 0.08);`

## Shapes

The geometric framework establishes clear distinctions based on component function:
- **Card Containers:** Standardized at `16px` border-radius (`rounded-xl` / `1rem`), giving a soft, modern perimeter to enterprise modules.
- **Tint Sub-Panels & Inset Groups:** Standardized at `12px` border-radius (`0.75rem`), nesting gracefully inside the `16px` outer cards with consistent `8px` perimeter concentricity.
- **Inputs, Buttons, and Select Triggers:** Standardized at `8px` (`0.5rem`), maintaining crisp, tactile affordance.
- **Semantic Pills & Taxonomy Indicators:** Fully rounded pill silhouette (`9999px`), distinguishing immutable category tags and metadata badges from interactive rectangular form elements.
