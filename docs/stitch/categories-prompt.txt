------------------------------------------------------------------------------
OVERALL LOOK — high fidelity, modern

A modern taxonomy studio in the Dominion design system, like Linear's settings or Notion's database properties, made calm and precise.

Surfaces and spacing:
- Page background: a very light cool grey.
- Cards: white, with a hairline 1px border, a 12–16px radius and a very soft shadow.
- Spacing: a strict 8px grid with generous whitespace.

Type:
- The Dominion sans for text.
- The Dominion mono with tabular figures for every code, slug, count and date.

Colour is restrained:
- Neutral greys almost everywhere.
- Dominion blue for selection, links and primary actions.
- Each group has a small 10px colour dot, using its own colour: peach #ffe6cc, mint #d5e8d4, butter #fff2cc, rose #f8cecc, lilac #e1d5e7. Group colours appear ONLY as these dots, never as row backgrounds.
- Green is used only for "In use".
- Amber is used only for "Not used yet" hints.
- A muted red is used only for the danger "Retire" button.

Micro-details: hairline dividers, small pill chips, focus rings, skeleton shimmer, a subtle hover tint, and smooth tree expand chevrons.

Keep it real: no glassmorphism, no gradients, no 3D, no illustrations, no AI badges, no "REGION" badges or "LOC:" footers.

Shell: the existing Dominion admin shell.
- The left sidebar is dark navy, with "Places and Maps" selected.
- The top bar is white, with the search field "Search entities, engines, routes…" and the avatar "DT · Deeki T · Owner".
