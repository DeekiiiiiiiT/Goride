Roam Dominion - Parts database, "Cars it fits" (Desktop Admin, for the owner):

Design high-fidelity desktop screens for the part drawer in Dominion's Parts database, and for the "Cars it fits" step of "Add a part". The owner loads which cars a part fits from the part maker's own catalogue (for example SB and NiBK list 92 cars for one front brake pad). Some cars are named exactly by the maker (Confirmed); others are close but not named exactly — a different chassis code or a year range that goes past the maker's list — so they go in as Needs checking. Today Dominion only records one trust level for the whole part. These screens let the owner set trust and the source page for each car, see it in the list, and change it later.

Dominion is the master parts database. Everything is stored; odd values get a label, never blocked. No prices, suppliers, stock or customer records. Everything else on the part drawer and in Add a part stays as it is.

- **Source:** opens the source page in a new tab.
- **Focus:** keyboard reachable rows and buttons, existing Dominion focus rings.
