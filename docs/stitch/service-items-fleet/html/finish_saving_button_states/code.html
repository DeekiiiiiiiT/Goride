1. Debounce Threshold

Prevent multiple simultaneous RPC invocations. If the previous trigger hasn't timed out, render State 02 within 150ms of duplicate clicks.

2. Resilience & Data Safety

State 03 copy explicitly assures users that local offline transactions remain cached. Never purge dirty records until the server returns an ACK.

3. Transition to Done

On HTTP 200, swap amber warning banner for the emerald completed status, transition draft token #DS-491 to final order #KAC-8821, and replace the action with View.
