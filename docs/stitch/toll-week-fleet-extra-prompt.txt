ROAM FLEET — TOLLS IN WEEK RECONCILIATION: 4 MORE SCREENS — FULL DESIGN PROMPT (GOOGLE STITCH)




Roam Fleet - Tolls in Week Reconciliation, extra dialogs (Desktop Web App, for the fleet owner, fleet manager and fleet accountant):

Design four more in-app dialogs for the toll part of Week Reconciliation in Roam Fleet. They belong with the screens already made (Upload inputs, the Tolls step and its dialogs) and must look exactly like them. When Roam reads a toll or Uber file, a few rows sometimes can't be used because Roam doesn't know which of the fleet's drivers or cars they belong to. The first two dialogs let the person fix that on the spot, without leaving Week Reconciliation: say which driver an Uber driver is, and which car a plate belongs to. The third shows, row by row, what Roam read from a file. The fourth confirms all of Roam's "sure" toll matches in one go. The person using this is not an accountant. Every dialog asks one plain question and has one obvious button.


BRAND IDENTITY:
- Each dialog sits over the dimmed Week Reconciliation page, inside the existing Roam Fleet app frame (white nav row with the black "Roam Fleet" tile, the dark navy bar with "Switch vehicle or search hub…", the breadcrumb "Business Finance › Week Reconciliation · Week of 24 Aug 2026 · Rideshare"). Do not redesign the frame.
- Theme: "Calm finance desk" — clear, trustworthy, quiet and modern.
- LIGHT MODE (default):
  - Primary: near-black #030213 — main buttons
  - Page wash: #f8fafc; dialogs and cards: #FFFFFF with a soft shadow and a hairline border rgba(0,0,0,0.06)
  - Text: #0a0a0a; muted text: #64748b
  - Done / New: green #059669 on #ecfdf5
  - Problem / Needs a fix: amber #b45309 on #fffbeb
  - Already in: slate #475569 on #f1f5f9
  - Sure match: green #059669 on #ecfdf5
- DARK MODE: page #1c1c1e, cards #2a2a2d, border #3a3a3d, text #fafafa, muted #a1a1aa, primary buttons white with near-black text; green #34d399 on #064e3b; amber #fbbf24 on #451a03.
- Shapes: dialogs and cards 20px corners, buttons and inputs 12px, chips fully rounded.
- Typography: Inter. Dialog titles 22px semibold, body 15px, helper 13px. Money in tabular figures with "J$" and 2 decimals.
- Dates and times in plain words ("27 Aug, 2:37 PM"). Never ids, codes, hashes, scores or percentages.
- Buttons always look like buttons:
  - Primary = solid near-black with white text.
  - Secondary = white with a visible #cbd5e1 border and dark text.
  - Cancel = red border and red text.
  - Never underlined links, never grey text-only buttons.
- Sample data (real): drivers Kenny Gregory Rattray, Phillip Bailey, Sadiki Abayomi Thomas; cars Toyota Roomy 5179KZ, Toyota Sienta 8834HB, Suzuki Swift 9042PX; the Uber file "payments and trip activity" for 24–30 Aug 2026.


DESIGN PRINCIPLES:
- One question per dialog, one obvious primary button.
- Fix it here: the person never leaves Week Reconciliation to fix a row.
- Show what came from the file next to what it will be linked to, so the person can see they match.
- After a fix, the row is read again on its own; nothing else changes.
- One view per screen.
