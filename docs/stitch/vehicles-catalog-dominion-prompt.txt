Roam Dominion - Vehicles (Desktop Admin, for the owner and catalog editors, who are not mechanics):

Design a complete, modern, high-fidelity redesign of the "Vehicles" section in the Roam Dominion admin console. It holds the master list of every car version Roam knows (1,833 versions across 56 makers). Every app reads its cars from here, and Find parts, car specs and the Add parts flow all depend on it. Today finding one car means scrolling a long table of near-identical rows. Two rows can both read "Toyota · Roomy Custom G · 2016-11–2020-08 · Gas · Petrol · Hatchback · Active" with nothing to tell them apart. The car opens as a panel under the table, far from the row you clicked. Car specs (fluids, oil, wipers, tyres) sit at the very bottom with a bare dropdown, and the same fluid has to be typed once per sister car. The new section is search-first: maker → model → the versions as clear rows that say how they differ. Each car opens as its own page, with a clear Car specs section that can save the same spec to sister cars in one go. It must feel modern and calm, and a first-time owner must use it alone.

DESIGN PRINCIPLES:
- Desktop-first at 1440px; content column max 1120px. A 390px phone frame is included.
- Search first: one big search box finds any car by make, model, year, frame code or engine code, several words at once ("roomy 2019 4wd").
- Maker → model → version, each a clear step with logos; the versions list says in plain words how each row differs.
- One real car version = one row. If two rows are truly identical, the row shows an amber "Looks like a duplicate" pill.
- Clicking a car opens its own page (with a back arrow), not a panel under the table.
- KEEP UNCHANGED: the existing eye (quick view) button on each row still opens today's quick-view overlay, exactly as it is now. Clicking anywhere else on the row opens the new car page.
- Car specs have their own section with plain labels, an example for each, a source link, and "Also save to sister cars".
- Empty values say "Not on file". Nothing shows a fake zero.
- Back arrow at the top of every page; no action buttons at the bottom of long pages.

INTERACTIONS:
- **Search:** results update as you type; matches make, model, years, frame code and engine code, several words at once.
- **Maker tile / model card / version row:** opens the next level; the eye button opens the existing quick-view overlay unchanged.
- **Filter pills:** narrow the versions list.
- **Tabs:** switch sections on the car page; the URL changes so a tab can be linked.
- **Add / Edit spec:** opens the right panel; "Also save to these sister cars" saves the same spec to every ticked car in one save.
- **Add parts (from Parts on file):** opens Add parts with this car already selected.
- **Retire / Undo:** always an in-app dialog.
- **Keyboard:** "/" focuses search; Enter opens; Esc closes panels.
