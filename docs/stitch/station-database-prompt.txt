SCREEN 1 — STATION LIST

Design a desktop screen called "Station database" inside the existing Dominion admin shell. The left sidebar is dark navy with "Fuel" selected; the top bar is white with a search field and the owner avatar "DT · Owner". Use the Dominion design system: neutral greys for almost everything, one blue accent for links and selection, green for Verified, amber for Pending and for things to fix, grey for neutral states. Numbers and codes use the mono font already used on Dominion. Cards have 12px corners, a 1px light border and no heavy shadow. It should feel like a calm, dense, professional data workbench. Do NOT add a "REGION" badge, a "LOC:" footer, or any decorative status text.

HEADER
- Breadcrumb: Dominion / Master data / Fuel / Station database
- Title "Station database". Subtitle: "The master list every Roam app matches fuel stations against."
- Right side: secondary button "Export CSV" and primary blue button "+ Add station".

SUMMARY STRIP (one slim card, a single row of linked counts separated by thin dividers, no big KPI tiles):
"204 stations" · "56 verified" (green dot) · "148 pending" (amber dot) · "10 with a live price" · "5 issue types" with an amber chip and the link "View issues ›"

TABS under the strip: "Stations 204" (selected) and "Resolution 7" (with a small count badge).

SEARCH AND FILTERS (inside the list card, top):
- Search field, wide: "Search name, alias, brand, address or plus code"
- A row of compact dropdowns: Status: All · Parish: All parishes · Brand: All brands · Pin: All · Source: All · Issue: All, then a text link "Reset".
- Below that, a row of toggle chips: "Verified", "Pending", "Possible duplicate 17", "No brand 65", "Parish text mismatch 72", "Pin unchecked 204". "Possible duplicate" is shown pressed (selected).

TABLE (50 rows per page; show about 12). Columns:
☐ | Station | Brand | Parish | Status | Pin | Geofence | Price (E10-87) | Fills | Issues | Updated | ›
- Station cell: name in semibold with the address under it in small grey text.
- Brand: e.g. "TotalEnergies", or "No brand set" in muted italic.
- Parish: e.g. "Saint Andrew". On some rows add a small amber dot after the parish (tooltip: "Stored text says Kingston").
- Status pills: "Verified" (green outline), "Pending" (amber outline), "Duplicate" (grey).
- Pin pills: "Unchecked" (grey), "Confirmed" (green), "Offset" (amber).
- Geofence: "150 m", "75 m", or "default" in muted text.
- Price: "J$225.40" in mono, or "—". One price has a hollow dot (outdated).

- Issues: small chips, up to 3, e.g. "Possible duplicate", "No brand", "Pin unchecked", then "+1".
- Updated: "2h ago".
