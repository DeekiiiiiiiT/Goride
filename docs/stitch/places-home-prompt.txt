ROAM DOMINION — PLACES AND MAPS HOME FULL DESIGN PROMPT (GOOGLE STITCH)




Roam Dominion - Places and Maps Home (Desktop Admin, for the owner):

Design a high-fidelity desktop admin home page for "Places and Maps", the master-data section that holds Jamaica's map (country, parish, town and community borders) and every place the Roam apps can find (gas stations, toll plazas and more). The owner and data staff open this page to see in five seconds whether the map is healthy, how many places still need fixing, what the Roam Plug app can show right now, and what is waiting for a decision. It is a calm operations overview, not a marketing page. It must look and feel like the existing Fuel home in the same app: a KPI row, a "Needs you" list, a side card, and section cards.

BRAND IDENTITY:
- Match the existing Roam Dominion admin style:
  - dark navy left sidebar
  - white top bar with the search field "Search entities, engines, routes…" and the owner avatar "DT · Deeki T · Owner"
  - white cards, hairline borders, compact rows
- LIGHT MODE (default):
  - Primary: Dominion Blue (#0153dc) — links, primary buttons, progress bars, the active sidebar item
  - Primary container: Pale Blue (#dbe1ff) — count pills, icon tiles
  - Success / healthy / on Plug: Green (#006e31)
  - Warning / needs work: Amber (#d97706)
  - Error / failed: Muted Red (#a83836)
  - Neutral: Slate (#797a84) — borders, muted text, icons
  - Background: Cool off-white (#faf8fe)
  - Surface cards: Pure white (#FFFFFF)
  - Text primary: Charcoal (#30323b)
  - Sidebar: Dark navy (#0f172a) with white text; the active item is a solid Dominion Blue pill
- DARK MODE:
  - Primary: #5b8def
  - Primary container: #1e3a5f
  - Success: #4ade80
  - Warning: #f59e0b
  - Error: #f87171
  - Neutral: #94a3b8
  - Background: Deep navy (#0b1220)
  - Surface: #111a2e
  - Text primary: #e2e8f0
- Count pills: small mono numbers in a pale pill; amber pill when the row is a warning
- Warning lines: amber icon + amber-tinted strip, the number always stays visible
- No gradients on data, no glassmorphism, no 3D, no illustrations. No AI badges, "REGION" badges or "LOC:" footers. No Rush delivery words ("Serviceable", "Paused", "Delivery zone").
- Typography: Inter for text. Every number, count, date and time uses the mono font with tabular numerals. Big KPI numbers are large and light, not heavy.
- Jamaica context: the 14 parishes, 131 towns, 775 communities; local fuel brands (TotalEnergies, Rubis, Texaco, FESCO); toll plazas on Highway 2000

DESIGN PRINCIPLES:
- Desktop-first (1440px wide), with a phone version
- Answer "is anything wrong or waiting?" before anything else
- Every number has a unit or an "of N" line, and every score shows its reason
- Two separate scores: the map's borders, and the places — never one blended number
- Warnings never hide numbers; they sit next to them
- Every row and card leads somewhere with one click
- Same structure as the Fuel home so the two pages feel like siblings
- Light theme default, dark mode variant
- Strict 8px spacing grid, 12–16px card corners, very soft shadows, subtle hover lift on cards, skeleton loading

INTERACTIONS:
- Clicking any "Needs you" row or button opens the matching page with its filter already applied:
  - Review: the review list with the matching chip.
  - Pins, brand and area rows: the Places register filtered to that issue.
- Clicking the map card opens the Jamaica map
- Clicking a section card opens that section
- Refresh reloads all numbers and updates the "Updated" time; the numbers never jump to zero while loading
- Rows with a count of zero are hidden; when every row is zero, the empty state shows
- Hovering a KPI mini bar shows "pass / total" in a tooltip
- Cards lift slightly on hover; every button has a visible focus ring for keyboard use
