Roam Dominion - Parts Database (Desktop Admin, for the owner):

Design a high-fidelity desktop admin section called "Parts database" inside the Vehicles area of Roam Dominion, the master reference database for Jamaican fleet vehicles (mostly Japanese imports: Toyota Roomy, Honda Fit, Toyota Vitz, Nissan Note). The owner is not a mechanic. They search a car, for example "Toyota Roomy 2019", and see every part that fits it in exactly five match types: Direct OEM Match, Sister Vehicle Match, Engine Compatible Match, Aftermarket Cross-Reference and Universal Fleet Parts. They add a part once, on the car the source talks about, with a source link, and the system shows where else it fits. No customer fleets, vehicles or stock ever appear here. It is a calm, data-dense tool, not a marketing page, and it must feel like a sibling of the existing Fuel and Places homes.

BRAND IDENTITY:
- Match the existing Roam Dominion admin style:
  - dark navy left sidebar
  - white top bar with the search field "Search entities, engines, routes…" and the owner avatar "DT · Deeki T · Owner"
  - white cards, hairline borders, compact rows
- LIGHT MODE (default):
  - Primary: Dominion Blue (#0153dc) — links, primary buttons, active tab, the active sidebar item
  - Primary container: Pale Blue (#dbe1ff) — count pills, icon tiles
  - Success / verified: Green (#006e31)
  - Warning / needs checking: Amber (#d97706)
  - Error: Muted Red (#a83836)
  - Neutral: Slate (#797a84) — borders, muted text, icons
  - Background: Cool off-white (#faf8fe)
  - Surface cards: Pure white (#FFFFFF)
  - Text primary: Charcoal (#30323b)
  - Sidebar: Dark navy (#0f172a) with white text; the active item is a solid Dominion Blue pill
- DARK MODE:
  - Primary: #5b8def
  - Primary container: #1e3a5f
  - Success: #4ade80
  - Warning: #f59e0b
  - Error: #f87171
  - Neutral: #94a3b8
  - Background: Deep navy (#0b1220)
  - Surface: #111a2e
  - Text primary: #e2e8f0
- Match-type colour tabs (a 4px left bar on each section header, never a full fill):
  - 1 Direct OEM Match: Dominion Blue
  - 2 Sister Vehicle Match: Teal (#0e7490)
  - 3 Engine Compatible Match: Violet (#6d28d9)
  - 4 Aftermarket Cross-Reference: Slate (#475569)
  - 5 Universal Fleet Parts: Green (#006e31)
- Status chips: "Verified" green outline chip; "Needs checking" amber outline chip; "Not on this car" grey chip
- No gradients on data, no glassmorphism, no 3D, no illustrations. No AI badges, "REGION" badges or "LOC:" footers.
- Typography: Inter for text. Part numbers, chassis codes, engine codes, years and counts use the mono font with tabular numerals.

DESIGN PRINCIPLES:
- Desktop-first (1440px wide), with a phone version of Find parts
- The five match types always appear in the same order, even when empty
- Every part row shows its source link; nothing looks verified without one
- Plain words only: never "interchange group", "fit scope", "rule", "platform family", "catalog variant" or "op code"
- One click from any car to its parts page, and from any part to the car it was listed for
- Light theme default, dark mode variant
- Strict 8px spacing grid, 12–16px card corners, very soft shadows, skeleton loading

SCREEN 2: PARTS DATABASE — FIND PARTS
- Breadcrumb: DOMINION › MASTER DATA › VEHICLES › PARTS DATABASE
- Title "Parts database", subtitle "Every part that fits a car, in five match types."
- Tab bar: Find parts (active) · Vehicle parts · Sister vehicles · Universal parts · Import — and a small "Advanced" text link at the far right
- Search card: three pickers in one row — Make "Toyota", Model "Roomy", Year "2019" — and a primary button "Find parts"
- Variant chips under the pickers, with the question "Which one?": "M900A · 2WD · 1KR-FE · 2016–2020" (selected) and "M910A · 4WD · 1KR-FE · 2016–2020"
- Coverage strip: "Service essentials 6 of 10 · Specs 4 of 13 · Other parts 12" and a secondary button "Open this vehicle's parts page"
- Five stacked section cards, each with the coloured left bar, a mono count pill and a one-line definition:
  1. "Direct OEM Match" — "Exact factory part for this car." Rows: job/category, brand + part number (mono), position, source link icon, status chip. Sample: Oil filter · Toyota 00000-00000 · — · link · Verified
  2. "Sister Vehicle Match" — "Same car under another badge: Toyota Tank, Daihatsu Thor, Subaru Justy." Each row adds a grey "Listed for Daihatsu Thor" line
  3. "Engine Compatible Match" — "Engine parts from cars with the 1KR-FE: Vitz, Passo, Boon." Each row adds "Listed for Toyota Vitz KSP130"
  4. "Aftermarket Cross-Reference" — "Other brands for the same part." Rows show brand + number and "Replaces OEM 00000-00000"
  5. "Universal Fleet Parts" — "Bought by size: bulbs, fluids, wipers, battery." Rows: spec label, value (mono), unit, and matching brand items as small chips; sample "Wiper, driver side · 525 mm · U-hook"
- An empty section shows "None on file yet" and a text button "Add for this vehicle"
- All sample part numbers are obvious placeholders (zeros), never real-looking numbers
