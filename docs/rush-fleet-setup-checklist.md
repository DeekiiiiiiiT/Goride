# Rush fleet — post-signup setup checklist

Vertical-aware onboarding steps shown in Settings after signup.

## Rideshare-only

- [ ] Import first trip batch (Imports)
- [ ] Add drivers and vehicles
- [ ] Configure earnings policy
- [ ] Connect fuel cards (optional)

## Delivery-only

- [ ] Enable rollout flags 1→4 (Dominion)
- [ ] Create workforce invite for first courier
- [ ] Assign vehicles to couriers
- [ ] Verify projection + recon zero drift (7 days)

## Both lines

- [ ] Complete rideshare + delivery items above
- [ ] Confirm scope switcher filters Dashboard, Finance, Settlements, Reports
- [ ] Manual week reconciliation before `rush_settlement`

Service lines can be updated anytime under **Settings → Service lines** (`ServiceLinesSettingsCard`).
